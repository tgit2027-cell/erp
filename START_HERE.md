# Tivoli ERP — Replit development package

Prepared 16 October 2026. New private project. Synthetic data only. Production hosting is undecided.

## Start

Create a private Replit project under a Tivoli-controlled account/workspace. Verify project visibility and preview access; project privacy alone does not establish that a published app is private. Do not publish publicly or purchase a plan from these instructions.

Upload/extract this package into the project, preserving file names. Put `replit.md` at the project root. Paste the contents of `01_FIRST_MESSAGE.txt` into Replit Agent. Work only on Milestone 1. Use the technical documents under `specs/` as reference; the milestone file controls the current implementation scope.

If privacy or the requested stack is unavailable on the account, report the specific limitation before proceeding. No production records, passwords, existing Microsoft exports or payroll files should be uploaded.

## What this package contains

- `replit.md`: persistent project rules and architecture boundaries.
- `01_FIRST_MESSAGE.txt`: initial Agent instructions, ready to paste.
- `MILESTONE_1.md`: precise first build and acceptance requirements.
- `MILESTONE_ROADMAP.md`: later increments, not authority to implement all at once.
- `REVIEW_HANDOFF.md`: evidence to return for independent review.
- `specs/`: custom architecture and technical foundation references.

The first deliverable is a real, persisted application shell with PostgreSQL, synthetic organization data and tested server permissions. Transaction posting arrives in Milestone 2. This avoids a polished shell being mistaken for a finished financial system.

## Return for review

Provide the project URL and a source export or access to its repository, along with the completed REVIEW_HANDOFF.md and test output. Do not include `.env`, secrets, database connection strings, session cookies, virtual environments or real business data. A private URL alone may not grant the reviewer access.

No Replit project or application has been created by this package. No tests have been executed against an application yet. Code generated later must be reviewed on its actual merits.
