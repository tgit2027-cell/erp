name: Complete started workflows independently
description: Pending policy on one proposed feature is not a global stop on authorized ERP completion work.
---

When asked to continue implementation, a missing decision blocks only behavior
that depends on it. Inspect actual started forms, integration/error states,
focused pages and end-to-end acceptance gaps before concluding no work can
proceed. Prioritize Retail team-testing completion, then started Inventory and
Procurement work, using existing permissions and disposable synthetic data.

**Why:** The owner explicitly corrected stopping all development on the
warehouse-transfer authority question. The instruction is to finish already-
started development, not invent new policy or keep proposing blocked features.

**How to apply:** Keep each pending decision named and unchanged, but complete
independent permitted journeys and fix reproduced defects. Distinguish workspace
implementation, technical evidence, team acceptance and production readiness.
This is not permission to implement during read-only/status requests.
