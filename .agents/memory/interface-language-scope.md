---
name: Interface and customer-document language
description: Owner-confirmed English internal ERP versus bilingual customer quotation/invoice documents.
---

Internal ERP menus, forms, validation, dashboards, reports and Finance
draft/recurring editors use English only. Only customer quotation and invoice
documents require English/Arabic presentation.

**Why:** The owner explicitly clarified that the prior bilingual requirement
applies to client documents, not the ERP itself.

**How to apply:** Use English interface and accessible labels. Retain optional
Arabic business/customer/item/document/account fields and stored values; those
are content, not interface translations. Preserve bilingual customer document
rendering and historical snapshots; never delete Arabic data to change UI
language. Historical bilingual-internal-UI requirements are superseded.
